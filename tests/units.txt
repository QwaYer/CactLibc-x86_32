#   "<unit> <test-main> <sources...> [link flags...]"
#     <unit>          selects tests/host/rename_<unit>.h, pre-included in every
#                     source of the unit
#     <test-main>     tests/host/<test-main>.c, the main() that runs the checks
#     <sources...>    src/<source>.c, the shipped code under test
#     -flags          anything starting with '-' is added to the link line
